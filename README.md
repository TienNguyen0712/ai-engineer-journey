# AI Engineer Journey

### AI Engineer là làm gì ? 

Một kỹ sư AI không như Nhà khoa học dữ liệu (DS) hay một Nhà nghiên cứu học máy. Họ chính là người mang sự tuyệt diệu của các mô hình AI vào sản phẩm thực tế
- Điều chỉnh, giám sát và deploy mô hình AI vào hệ thống sản phẩm
- Thiết kế nhiều mô hình LLM như điều phối, lan truyền ngược và tổi ưu hóa giá trị
- Dựng hệ thống RAG, AI agents và flow tự động
- Biết khi nào dùng OpenAI Claude Gemini
- Đưa ra đánh đổi, an tính và bảo mật cho hệ thống sử dụng AI

### Kỹ sư AI vs Kỹ sư Học máy 

| AI Engineer | ML Engineer |
|---|---|
| Dùng pre-trained models với APIs | Huấn luyện mô hình từ đầu |
| Chỉnh API, dặt prompt | Dựng ống dữ liệu, Đánh giá |
| Nhnah triển khai | Đắt, đòi hỏi nghiên cứu sâu |
| Product + dev expertise | Hiểu sâu về ML/math |
| **You are this** | Data science role |

### Thị trường cần 2026

- Giám sát nhiều LLM (OpenAI + Claude + Gem)
- RAG + Vector database
- LLMOps & production monitoring
- Prompt engineering at scale
- Fine-tuning & PEFT methods
- MCP (Model Context Protocol)
- Multimodal AI systems
- Cost optimization & inference


Các nguồn tham khảo: https://ml-cheatsheet.readthedocs.io/en/latest/
